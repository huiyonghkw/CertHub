What counts as one certificate?什么算一张证书？

01
One certificate record, one slot一条证书主记录，占一个槽位

A wildcard certificate such as *.example.com counts as one certificate.例如 *.example.com 泛域名证书，也只计算一张。

02
Deployment targets do not multiply the count部署目标数量不重复计费

The same certificate deployed to multiple servers still occupies one slot.同一张证书部署到多台服务器，仍然只占一个槽位。

03
Inactive records release capacity停用证书可释放额度

Disabled or deleted certificate records release their slots for reuse.停用或删除证书记录后，槽位可以重新使用。
